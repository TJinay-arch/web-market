![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

**Web Market** — простой интернет-магазин на Django с админ-панелью, корзиной и оформлением заказов. Проект использует встроенную систему шаблонов Django, сессии для корзины и SQLite в качестве базы данных.

---

## 📋 Функционал

- [x] Просмотр каталога товаров
- [x] Добавление товаров в корзину (через сессии)
- [x] Оформление заказа
- [x] Админ-панель Django:
  - Управление товарами
  - Просмотр заказов
- [x] Адаптивный интерфейс (Bootstrap 5)
- [x] Локальная база данных (SQLite)

---

## 🚀 Запуск проекта

### 1. Клонируйте репозиторий
bash git clone https://github.com/TJinay-arch/web-market.git cd web-market


### 2. Установите зависимости
bash pip install -r requirements.txt (либо используя poetry)

### 3. Запустите сервер
python manage.py runserver

### 4. Откройте в браузере

- 🌐 Пользовательский интерфейс:  
  [http://127.0.0.1:8000](http://127.0.0.1:8000)
